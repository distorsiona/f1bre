# Fotografías de carreras para Home

Coloca aquí tus fotografías en JPG o PNG. El nombre coincide con `circuit_short_name` de OpenF1 en minúsculas, sin espacios, tildes ni signos.

Ejemplos: `monza.jpg`, `silverstone.jpg`, `yasmarinacircuit.jpg`, `suzuka.jpg`, `spafrancorchamps.jpg`.

Home intenta primero JPG y luego PNG. Si no existe ninguno, conserva un espacio neutro con el nombre del circuito. No descarga ni genera fotografías automáticamente.

La imagen se ajusta al panel con `object-fit: cover`: una fotografía horizontal funciona mejor. El archivo original no se modifica. Las fotografías son opcionales y no bloquean la carga de resultados.
